# AI Workplace Productivity Assistant

A modern, responsive SaaS web application that uses AI to help professionals complete common workplace tasks more efficiently.

The **AI Workplace Productivity Assistant** provides AI-powered tools for generating professional emails, researching and summarising information, and planning daily or weekly tasks. The application is designed with a clean, professional dark-mode interface and accessibility in mind.

## Project Overview

The AI Workplace Productivity Assistant is a frontend-focused productivity application.

The goal of the application is to reduce the time users spend on repetitive workplace tasks by providing AI-assisted tools that dynamically respond to the user's actual inputs.

The application includes three primary productivity tools:

* **Smart Email Generator** – creates professional emails based on the user's purpose, recipient/context, key points and selected tone.
* **AI Research Assistant** – analyses topics, article text or website content and produces summaries, key insights and practical recommendations.
* **AI Task Planner** – organises tasks, deadlines, priorities and available working hours into an actionable daily or weekly schedule.

The application is intentionally frontend-focused and does not require a custom backend, authentication system or database.

Users can provide:

Users can provide:

* Key insights

* Practical recommendations

Users can enter:

* Tasks
* Deadlines
* Priorities
* Available working hours

The AI generates a practical schedule that:

* Prioritises tasks
* Organises work into available time
* Produces daily or weekly plans
* Can be edited by the user after generation

### ♿ Accessibility Mode

The application includes an **Accessibility Mode** that provides a more visually accessible interface.

When enabled, it provides:

* Larger text
* Stronger colour contrast
* Clearer focus states
* Reduced visual effects
* Keyboard-friendly navigation
* Screen-reader-friendly labels

The accessibility experience is designed to make the application easier to use for people with different visual, motor and accessibility needs.

### ⚠️ Responsible AI

A visible disclaimer is included throughout the application:

> AI-generated content may contain errors. Review important information before using or sharing it.

Users are encouraged to review AI-generated information before relying on it for important workplace decisions or sharing it with others.

### 💾 Local Storage

Because the application does not use a custom backend or database, appropriate user preferences and drafts can be stored locally in the browser.

This can include:

* Accessibility preferences

* Email drafts

## Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/your-username/ai-workplace-productivity-assistant.git
```

### 2. Navigate to the project directory

```bash
cd ai-workplace-productivity-assistant
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure the AI service

If the project uses an external AI API, create a `.env` file in the root directory and add the required API configuration.

For example:

```env
VITE_AI_API_KEY=your_api_key_here
```

**Do not commit API keys or other sensitive credentials to GitHub.**

Add `.env` to `.gitignore` if it is not already included.

### 5. Start the development server

```bash
npm run dev
```

The application should then be available through the local development URL provided by Vite, typically:

```text
http://localhost:5173
```

### 6. Build for production

To create a production build:

```bash
npm run build
```

The production files can then be previewed locally with:

```bash
npm run preview
```

## AI Implementation Principles

The application is designed around the following AI principles:

1. **Dynamic input handling**
   AI responses should be generated from the user's actual inputs.

2. **Feature-specific prompts**
   Each productivity feature uses structured prompts appropriate to its task.

3. **No hardcoded AI responses**
   Demonstration text should not be used as a substitute for actual AI generation.

4. **Human review**
   AI output should be treated as assistance rather than automatically verified information.

5. **Clear AI attribution**
   Users should be able to distinguish AI-generated content from information supplied by an original source.
